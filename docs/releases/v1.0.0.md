# Workspace 1.0

Notes, docs and databases in one app that keeps your work on your computer, with an optional
server you run yourself for sync, sharing and a web app. Everything Notion does, except its AI.

## Install

On Ubuntu 24.04 or later, pick one:

- **apt** (updates with the system): see [Install](../desktop.md#install) in the desktop guide.
- **`.deb`**, **AppImage** (updates itself), **Snap** or **Flatpak**: download from this release.

Check a download with `SHA256SUMS` and its signature, `SHA256SUMS.asc`.

The server runs with Docker Compose: see the [self-hosting guide](../self-hosting.md).

## What's in it

- **Pages:** every block type (headings, lists, to-dos, toggles, callouts, code, equations,
  Mermaid, tables, columns, synced blocks, buttons, media and embeds), slash menu, Markdown
  shortcuts, drag and drop, comments and page history.
- **Databases:** table, board, list, gallery, calendar, timeline, chart and form views; every
  property type, formulas, relations, rollups, templates and automations.
- **Sync and collaboration** through your own server: real-time editing, sharing per page and
  teamspace, an inbox, publishing pages to the web, and a web app that works offline.
- **Import** from Notion, Evernote, Trello and Confluence, and Markdown, HTML and CSV;
  **export** to Markdown & CSV, HTML and PDF, and full backups.
- **An API** in Notion's shape, so existing Notion integrations can point at your server.
- **Accessibility** (keyboard paths and screen reader labels throughout), zoom, light and dark
  themes, and your region's date and number formats.

See [the full feature list](../features.md).

## Known limits

- The interface is in English only.
- No custom domains for published sites, embeds only from the common sites (YouTube, Vimeo,
  Loom, Figma, CodePen, Google Maps), and no filters in quick find yet.
- The Snap and Flatpak are new with this release; report anything odd with them.
